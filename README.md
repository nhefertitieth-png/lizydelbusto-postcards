# Lizy del Busto — Postcards

Public image host for the illustrated postcard line, used to supply product
image URLs to wholesale marketplaces (Faire).

Twelve designs, English edition. Each has a **hero** shot (flat lay, card +
envelope) and a **hand** shot (held, showing back and front).

## Naming

`ldb-pc-<design>-<lang>-<NN>-<view>.jpg`

`ldb` = lizydelbusto, `pc` = postcard. Views: `01-hero`, `02-hand`.

## Known issues

Hand shots below full resolution (1024x1024 instead of 2048x2048), worth
re-rendering before use as a primary listing image:
`cake`, `limited`, `pet`, `baby`, `normal`, `cheer`, `loading`,
`process`, `blooming`, `favorite`.

On `cheer` and `favorite` the hand shot has the blank back of the card on
top, so the artwork is largely hidden. Neither should be a lead image.

All mockups are 72 dpi presentation renders, not print-ready artwork.
