# Lizy del Busto — Postcards

Public image host for the illustrated postcard line, used to supply product
image URLs to wholesale marketplaces (Faire).

Six designs, English edition. Each has a **hero** shot (flat lay, card +
envelope) and a **hand** shot (held, showing back and front).

## Naming

`ldb-pc-<design>-<lang>-<NN>-<view>.jpg`

`ldb` = lizydelbusto, `pc` = postcard. Views: `01-hero`, `02-hand`.

## Notes

- `main` and `frog` hand shots are 2048x2048; the other four are 1024x1024
  and should be re-rendered before they are used as primary listing images.
- Mockup renders at 72 dpi — presentation only, not print-ready artwork.
